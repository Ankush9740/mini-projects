# APEX MOTO — The Art of Riding

Five-page responsive static motorcycle showcase.

## Run
Open `index.html` directly in a modern browser. No build step or server needed.

## Pages
- `index.html` — cinematic homepage
- `collection.html` — motorcycle grid and category filters
- `details.html` — selectable machine details (URL query `?bike=0` through `?bike=3`)
- `engineering.html` — motorcycle engineering features
- `contact.html` — story and frontend-only validated form

## Stack
HTML, CSS, vanilla JavaScript, optional GSAP/ScrollTrigger via CDN. Fonts and images are remotely hosted; internet is required for those resources. If GSAP is blocked, core content and functionality remain accessible.

## Notes
- This is an independent concept website, not affiliated with Ducati, BMW, Kawasaki, or Triumph.
- Motorcycle specifications are representative claimed figures and vary by year/market. Verify before publication.
- Photos are editorial motorcycle photography and **not verified exact model photographs**. Replace with licensed, model-accurate images before a public launch.
- Contact form validates locally only; it does not send or store messages.
- Reduced-motion preferences are supported.

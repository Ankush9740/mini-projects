# SHINOBI Chronicles — The Ninja Way

An unofficial Naruto-inspired, five-page, responsive fan website.

## Start
Extract the ZIP and double-click `index.html`. No server, build step, or npm install required. An internet connection is needed for Google Fonts, GSAP CDNs, and external Unsplash landscape photos.

## Pages
- `index.html`: Cinematic homepage
- `characters.html`: Interactive shinobi roster and filters
- `villages.html`: Five major hidden villages
- `story.html`: Spoiler-light timeline and click-to-expand gallery
- `contact.html`: About and client-side validated demo form

## Structure
- `css/style.css`: Shared styling and responsive breakpoints
- `js/main.js`: Shared navigation, loader, animations, filters, counters, gallery, form
- `assets/`: Reserved for local assets

## Notes
- Uses GSAP + ScrollTrigger loaded by CDN; if offline, content remains visible and functional except animation enhancements.
- Images are real-world Japan/landscape photography for mood, **not** anime frames or representations of fictional characters. Character cards use original typographic compositions.
- No form data is sent or saved.
- Unofficial fan project; Naruto and related characters are property of their respective rights holders.
- Honors `prefers-reduced-motion`.

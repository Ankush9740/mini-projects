# INDIA — Beyond the Ordinary

Premium five-page static tourism showcase built with HTML, CSS, vanilla JavaScript and GSAP ScrollTrigger.

## Run
Extract the ZIP, then open `index.html` in a modern browser. No server, build step or database is required. An internet connection is needed for Unsplash photos, Google Fonts and GSAP CDN scripts.

## Pages
- index.html — Home
- destinations.html — Destinations with working filters
- experiences.html — Experiences
- heritage.html — Heritage
- contact.html — About and contact form

## Features
Responsive layouts, mobile menu, hero reveals, scroll animations, image zoom, horizontal showcase, counters, page loader, reduced-motion support, frontend form validation. The contact form intentionally does not submit or save messages.

## Important
Images are remote Unsplash photographs selected for thematic fit; verify exact monument/region correspondence before public use. The site is an educational showcase and not an official government tourism portal. A few images are atmospheric rather than documentary. No backend or booking functionality.

# VICTUS / HP — Gaming Laptop Showcase

Five-page responsive static website concept for the HP Victus laptop family.

## Pages
- `index.html` — Overview
- `lineup.html` — Victus 15, Victus 16, and configuration guide
- `performance.html` — CPU, GPU, TGP, memory, display, and thermal buying guide
- `features.html` — Design, display, cooling, connectivity, and upgrades
- `contact.html` — About and frontend-validated contact form

## Technology
HTML5, CSS3, Vanilla JavaScript, GSAP 3 and ScrollTrigger via CDN. No framework, backend, database, or build process.

## Run
Extract the ZIP and open `index.html` in a modern browser. Internet is needed for online photographs, Google Fonts, and GSAP.

## Accuracy and trademark note
This is an unofficial fan-made concept, not affiliated with or endorsed by HP. Victus specifications vary by exact product number, generation, and region; verify the exact SKU against HP's official listing before purchase. The contact form validates in-browser only and does not transmit or store messages.

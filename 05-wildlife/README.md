# WILDERNESS — Explore the Wild

A five-page educational wildlife website built with HTML, CSS and vanilla JavaScript.

## Open
Extract the ZIP and double-click `index.html`. No installation or server is needed. Navigate using the menu.

## Pages
- `index.html` — home
- `wildlife.html` — animal directory and filters
- `habitats.html` — six habitats
- `conservation.html` — threats, species and actions
- `gallery.html` — photography gallery, lightbox and demo contact form

## Important: images and offline use
The environment used to generate this project could not download external photographs. Images are currently linked to Unsplash and require internet access; they are NOT bundled in `assets/images`. Specific photo IDs and their species matches have not been independently verified. The site is not fully offline-ready. Google Fonts also requires internet; system fallback fonts are supplied.

To make the site offline-ready, obtain appropriately licensed photos, verify species matches, download them into `assets/images/`, and replace the image URLs in the five HTML files with local paths. Record photographer credits and licenses.

## Features
Responsive menu, category filtering (categories overlap), scroll reveals, lightbox with keyboard controls, client-side form validation, and back-to-top control. The contact form does not send data.
